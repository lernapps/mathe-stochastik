# Skizze: ZufallMaschine (Kapitel experimente)

```
 Gerät: ( ) Würfel  ( ) Münze  ( ) Glücksrad  ( ) Urne  ( ) Reißzwecke
 Deine Schätzung für „Sechs“: [ 1/6 ▾ ]                  (vor dem Start)

 [ 1 Wurf ] [ 10 Würfe ] [ 100 Würfe ] [ 1000 Würfe ] [ Zurücksetzen ]

 Ergebnis   absolut   relativ
 1            17       0,17
 …
 6            15       0,15

 relative Häufigkeit
 0,3 |  *
 0,2 |    *  *  ..........  (Linie der Schätzung, gestrichelt)
 0,1 |
     +-------------------- Würfe (10 · 100 · 1000, Beschriftung als Zahl)

 Rückmeldung (Text): „Nach 10 Würfen schwankt es noch stark. Nach 1000 liegt es nahe bei deiner Schätzung.“
```
- Tastatur: Geräte als Radiogruppe, Knöpfe als Buttons; Tabelle mit Beschriftung; Diagramm mit Textalternative.
- Ohne JavaScript: feste Beispielreihe als Tabelle und Satz.
