# Skizze: Vierfeldertafel (Kapitel vierfeldertafel)

```
            krank   gesund  Summe        Baum (gleiche Zahlen):
 Test +      [ ]      [ ]    [ ]         krank 1 % ── Test + 90 %
 Test −      [ ]      [ ]    [ ]                    └─ Test − 10 %
 Summe       [ ]      [ ]   1000         gesund 99 % ─ Test + 5 %
                                                      └ Test − 95 %
 Aufgabe: Fülle die Lücken. Dann: Wie viele der positiv Getesteten sind krank?
```
- Eingabefelder mit Beschriftung (Zeile, Spalte); Zahl, Bruch oder Prozent.
- Rückmeldung nennt den Fehlertyp (Zeile statt Spalte, Bedingung vertauscht).
- Ohne JavaScript: ausgefüllte Beispieltafel als Tabelle und Baum als Text.
